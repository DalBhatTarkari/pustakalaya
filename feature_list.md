'Pustakalaya: An Online E-Library Catalogue' 



Site: https://pustakalaya.42web.io/

GitHub repo: https://github.com/DalBhatTarkari/pustakalaya/



Language Used:

* PHP
* JavaScript
* HTML
* CSS
* Database: MYSQL(MariaDB)



Common Features: 

* Pagination 
  (only dash.php default set to 12 books per page)
* Registration
* Login/Logout
* Change Password
* Account Recovery
  (Disabled in the site but code visible in the GitHub repo inside the file: forgotpassword.php and 			mailerfunction.php
  Reason: account password required )
* Client and Server-Side Validation using JS and PHP
* Role-Based access





Role Based Features:

1. User:

* Read approved books and search for approved/ under approval books,
* Bookmark and personal reading list,
* Request Books to be added to the site.



2\. Librarian:

* Approve/reject user requested books,
* Add new books as well as edit other books.



3\.  Admin:

* System Logs,
* User detail overview,
* Role assignment to users/librarians.
